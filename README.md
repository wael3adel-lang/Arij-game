# ARİJ OYUN

منصة ألعاب تعليمية للأطفال.

## طريقة الاستخدام
1. ارفع جميع الملفات إلى مستودع GitHub Pages.
2. افتح الرابط الرئيسي.
3. أعطِ كل طفل كودًا خاصًا به.
4. عدّل `config.js` لتحديد الألعاب المسموحة لكل طفل.

مثال:
`ARIJ01` → Sayı Avı فقط.

## ملاحظة مهمة
هذه النسخة مناسبة كبداية على GitHub Pages، لكنها ليست حماية أمنية حقيقية؛ لأن GitHub Pages موقع ثابت ويمكن لمن لديه معرفة تقنية اكتشاف الملفات أو تغيير الرابط.

إذا أردنا منع الوصول فعليًا، فالخطوة التالية هي ربط النظام بـ Supabase وإنشاء صلاحيات حقيقية لكل طفل.
